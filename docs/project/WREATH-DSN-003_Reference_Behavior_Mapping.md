## Method and honesty statement

On 2026-10-17 the official documentation sources listed in the register below were fetched and read. **Four ticket study sources were reviewed (R1–R4) plus the common S-expression definitions page (R6).** The KiCad source repository (R5) was **not** inspected; this is left unresolved per instruction.

Limits of this review, stated so the findings are not over-read:

- The retrieved pages were truncated by the retrieval tool. Findings below are limited to the sections that were actually rendered and read; nothing is filled in from memory.
- These are **reference behaviors only**. No reference behavior approves, ratifies, or settles any WREATH decision. Column 3 (intended WREATH behavior) and every `DEP-*` decision remain `PROPOSED` or `UNRESOLVED`.
- **No source code was downloaded, cloned, inspected, copied, or adapted.** Findings come from published documentation and file-format specifications only.
- Reference behavior is recorded to inform the WREATH design, not to be adopted by default. Where the reference differs from ticket sections 7.2 and 7.5, the difference is flagged rather than resolved.
- **PCB conventions are not inferred from schematic-only decisions (D1–D10).** The reference does document PCB-side conventions, but adopting them is a WREATH decision that has not been made.

This document maps:

1. The behavior the ticket requires.
2. The reference behavior and its source/evidence.

4. Unresolved differences or decisions.
